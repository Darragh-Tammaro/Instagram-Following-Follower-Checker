# Instagram-Following-Follower-Checker

A python script you can use to see who doesn't follow you back

# How To Use

1) Log into <b> Instagram </b> on a browser of your choice
2) Go to <b> settings </b>
3) Find the <b> Accounts Centre </b> and locate <b> "Your Information and Permissions" </b>
4) Click <b> "Export your information" </b>
5) Select only <b>"Followers and following"</b> as well as <b> "All time" </b> for the date range
6) Make sure format is set to <b> JSON </b>
7) Once downloaded, place the python script in the same folder as <b> following.json </b> and <b> followers_1.json </b>

# Extra information

NOTHING IN THE SCRIPT HAS TO BE CHANGED

Note:

During testing, some ghost entries where found - if you see an account in the list with an unfamiliar name just ignore it. These are either old follows you have forgotten about, renamed accounts, bought/bot accounts, banned/deleted accounts or a bug in Instagram's export system.
